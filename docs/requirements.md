# 需求证据与 MVP 范围

## 来源与优先级

2026-10-31 已读取[分享对话：Electron脚本注入工具](https://chatgpt.com/share/6ae5d51b-6158-83e8-9f82-5abfcb5f067a)全文。早期加载失败记录保存在[初始化证据](archive/T-001.md#t-001)，不再构成当前阻塞。

用户直接表达的目标：注入 JS/HTML/CSS，改变桌面应用 Web UI 的样式、组件和交互；长期扩展到 Electron 之外，包括 Tauri 等 Web 宿主。当前开发对话明确首发 macOS Electron，并补充 MVP 不需要 GUI，优先做好核心。

分享中的 Windows 优先、AI 编辑器、插件市场、Native Hook 等是原回答的建议，不作为本轮已批准需求。分享中的技术断言需要结合官方接口与本项目实测核验。

## 本轮最小核心合同

- CLI 发现指定本地调试端口暴露的页面，以精确 ID 选择单个目标。
- 从本地版本化 manifest 加载 CSS/HTML/JS，经过单一共享 Web runtime 执行。
- 同 ID 重复应用替换受管理内容，不累积节点；提供 remove 和脚本清理回调。
- 对不可连接、不支持、找不到目标、脚本异常与清理失败报告真实失败。
- macOS 标准 Electron .app 可生成启动参数规划；不自动重启、改包或结束用户应用。
- 架构将共享逻辑、协议与平台接入隔离。真实验证使用独立 Electron fixture。

Rust CLI 是本轮实现选择：面向长期原生接入与无需 Node 运行时的单可执行文件交付，接受编译成本；用户确认无需图形入口。Node/Electron 仅供测试，版本均锁定。

## 非本轮交付

自动启动与进程发现、页面导航重注入、跨窗口会话恢复、脚本持久化与权限系统、热更新、GUI、AI 生成、安装包发布、多平台/多引擎实现和原生 Hook。它们没有伪实现或成功占位命令；需要时基于真实用例建立后续任务。

## 证据边界

首批商业目标应用尚未指定。本轮验收覆盖受控 Electron fixture 的页面发现、样式、DOM、脚本交互、更新与移除，不能声称兼容所有 Electron 应用。受保护、未开放调试入口或页面策略阻止插入的应用可能不支持；CDP 返回成功也不保证任意 CSS/HTML 在所有页面产生预期视觉效果。
