# Figma：内部测试开关下的 CDP 接入验证

2026-11-03；[任务与执行](../archive/T-011.md#t-011)。macOS 26.5.1 arm64，Figma 126.5.6、Electron 41.7.0、Chromium 146.0.7680.216；使用现有 Injectra CLI，未修改产品源码或目标安装包。

## 结论与分类

本次仍是 **CDP runtime Web 注入**。`FIGMA_TEST=1` 是让当前 Figma 版本保留调试入口的宿主启动条件，不是新的注入后端，也没有实施 Hook、Frida 或原生内存操作。

- 已验证：回环调试入口可达；发现多个页面；对桌面外壳 `shell.html` 用现有 CLI 执行 HTML/CSS/JS 注入；测试条可见；首次实例的实际点击使计数从 0 变为 1。
- 后续重开复现测试条显示，但在线内容页空白。再使用本机现有代理显式启动并重启后，完整 Figma 登录页与外壳测试条同时显示。
- 未验证：登录后的设计编辑页面、用户文件操作、长期稳定性，以及这一应用上的完整更新／remove 回归。局部测试曾执行 remove，不计为全组基线通过。

不回填[原普查](macos-cdp-survey.md)的31次尝试／20个通过项，也不改变[后续排查](macos-cdp-followup.md)当时未实施 Figma 新路线的历史事实。

## 调试入口的本地源码证据

定向读取安装包 `Contents/Resources/app.asar` 内的 `main.js`，发现等价于下列逻辑的条件：

```js
process.env.FIGMA_TEST || app.commandLine.removeSwitch("remote-debugging-port");
```

正常启动会移除调试端口参数；设置非空的 `FIGMA_TEST` 后跳过移除。本次设置为 `1` 并请求回环调试端口，随后通过 `/json/list` 及页面执行确认入口可用。

这是当前安装版本的内部行为，未找到其作为公开稳定接口的保证；不能推广到其他版本。测试开关还影响关闭文件确认、更新和辅助组件等行为，因此本次只在独立测试配置中使用，不把它作为日常启动默认值。

## 配置隔离与精确页面选择

Figma 启动代码会自行用系统 `appData` 目录计算配置与 Chromium profile，并调用 `app.setPath("userData", ...)`；仅传 `--user-data-dir` 不能证明隔离。本次在仓库外测试目录中设置 `HOME` 与 `CFFIXED_USER_HOME`，先用 Foundation 路径探针核对 home／Application Support，再观察 Figma 实际创建相应配置目录。没有声称钥匙串、系统偏好或全部运行副作用得到隔离。

以下为本次人工启动条件的结构，变量须指向独立测试目录、空闲端口和实际安装包；不是新增 CLI 自动启动能力：

```sh
env HOME="$TEST_HOME" CFFIXED_USER_HOME="$TEST_HOME" FIGMA_TEST=1 \
  "$FIGMA_EXECUTABLE" --remote-debugging-address=127.0.0.1 \
  --remote-debugging-port="$CDP_PORT" --no-first-run
```

发现的目标包含本地 `shell.html`、在线文件／登录内容页以及空白窗口页面，不能按第一个 page 直接认定为设计页面。外壳视口只有约38 CSS像素高；最初居中面板超出该视口，最终使用顶部32像素高的独立测试条。之后以精确外壳目标 ID 执行现有 `apply` 命令。

## 黑窗口：恢复措施与根因边界

前两次实例中，发现接口显示在线目标 URL，但该目标内读回的 `location.href` 仍是 `about:blank`、正文为空；外壳测试条显示不能证明在线界面可用。日志同时出现网络服务崩溃或被终止后重启的信息，但这不是其根因证明。

本机系统代理当时为回环7897端口。第三次实例保留相同测试开关及独立配置目录，增加显式代理参数 `--proxy-server=http://127.0.0.1:7897` 并重启，随后确认内容页为 `Login | Figma`、`document.readyState=complete`、标题为 `Sign in to Figma`；完整原生窗口截图同时显示登录页和外壳测试条。

**证据支持代理／网络接入问题，但没有完成排他性根因确认。** 本次同时改变代理参数并重启，未做“仅重启、不改代理”的对照，无法区分代理自动识别异常与网络服务重启恢复。不能写成已证明未继承系统代理，也不能据此归因于进程过多。7897是本次环境事实，其他机器应使用自己的已验证代理配置或直接网络，不照抄该端口。

独立配置未继承常规登录态；登录页恢复不代表已进入设计编辑器。本次没有代为登录或读写设计文件，也未修改系统代理设置。
