Use a bug report for reproducible injector/backend failures and a feature request for a missing reusable capability. An application-specific theme or selector issue belongs in the payload's own project. For a research evidence discrepancy, include the source report and the precise claim; preserve the original run.

## Useful diagnostic information

Include the Injectra commit/tag, OS and CPU architecture, target app/version/engine, backend, command with private values removed, expected behavior, actual result, and execution certainty. A minimal reproduction using owned test content is preferable to a screenshot of a personal conversation.

Remove session keys, tokens, cookies, authorization headers, private URLs, profile contents, and user documents from attachments. Do not post an entire credentialed session or raw private cache. Use [the security channel](SECURITY.md) for sensitive reports.
